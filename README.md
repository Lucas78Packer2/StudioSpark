# AI Music Studio — Android (Kotlin + Jetpack Compose)

Native Android recode of the AI Music Studio Swift sources (SampleLibrary, StudioSession, MixerEngine, InstrumentSoundGenerator, InstrumentTakeRecorder, MixBounceRenderer, MixExportStorage, TrackCompressorUnit, SynthNote, ContentView). The app ID is `com.aimusicstudio.app`, with minSdk 26 and targetSdk 34.

## Tabs
- **Sounds**: a sample library that scans the app's `stems/` folder for wav/caf/aif/aiff/m4a/mp3 files. It cleans up `stem-` names, and you can search it, filter it by category, preview a sound by tapping it, or use **Add to track**.
- **Instruments**: 11 drum pads (Bass Drum…Cymbal), Sine/Tri/Saw/Square synths, and a 303-style acid bass. It includes a one-octave keyboard, **Add note to a track**, and a 16-step drum pattern.
- **Arrange**: a multitrack timeline. You can add or remove audio and synth tracks, zoom in and out, scroll, move/trim/delete clips (tap a clip, or use TalkBack custom actions), seek, see the loop region, and edit the selected synth track in a lite piano roll.
- **Mix**: each track has mute, solo, volume, pan, and a waveform picker. It also has a 3-band EQ and a compressor (threshold, ratio, attack, release, makeup gain), plus a master fader and meter.
- **Record**: records mic takes to WAV and adds each one as a new track. It asks for RECORD_AUDIO permission at runtime.
- **Session**: name, tempo, loop start/end, and master volume, plus save/new/open/delete (stored as JSON in app storage). **Bounce mix to WAV** writes to `Android/data/com.aimusicstudio.app/files/exports/`.

Transport (play, pause, stop, loop) is in the header. Mix edits apply the next time you press Play, because the engine renders the session offline and then streams it through `AudioTrack`.

Demo stems in `app/src/main/assets/stems/` are short tones and drums generated by a script. They get copied into app storage on first launch.

Notes: the iOS project, workspace, and `ENCRYPTED_KEYS.plist` are not shipped and none of their values are embedded. The only Info.plist entry mapped over is the microphone usage text. The launcher icon is made from the orange-teal mixer PNG.

## Open / install
- **Android Studio**: File → Open → select this folder, let Gradle sync, then Run on a device or emulator.
- **Prebuilt APK**: enable USB debugging and run `adb install -r AIMusicStudio-debug.apk`. Or copy the APK to the phone, open it, and allow "Install unknown apps".
- **CLI build**: `./gradlew assembleDebug` (needs JDK 17 and the Android SDK 34). The output goes to `app/build/outputs/apk/debug/app-debug.apk`.
